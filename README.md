# مدرستي — تطبيق إدارة المدرسة للأندرويد

تطبيق عربي لإدارة الطلاب والمعلمين والصفوف والحضور والغياب ومرافق المدرسة، مع تقارير ونسخ احتياطية.

## تنزيل APK
بعد نجاح البناء التلقائي، افتح تبويب **Actions** ثم اختر **Build Madrasati APK** وافتح أحدث تشغيل ناجح، ونزّل ملف **madrasati-debug-apk** من قسم Artifacts.

## ملاحظات النسخة الأولية
- البيانات محفوظة محلياً على الجهاز داخل التطبيق.
- صدّر نسخة احتياطية بانتظام؛ حذف التطبيق أو مسح بياناته قد يؤدي إلى فقدان البيانات المحلية.
- لا توجد حالياً مزامنة سحابية أو حسابات مستخدمين.
- الطباعة تعتمد على نافذة الطباعة المتاحة للجهاز، ويجب اختبارها على الهاتف بعد تثبيت التطبيق.
